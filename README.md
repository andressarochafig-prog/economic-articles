## Sobre o projeto

Sou estudante de Ciências Econômicas e sempre precisei de um lugar para fazer o que mais gosto: pegar algo do cotidiano e destrinchar o porquê econômico por trás. Escreverei assuntos sempre trazendo dados, macroeconomia, comportamento do consumidor e estruturas de mercado. O Paren(theses) nasceu da vontade de unir escrita, programação e análise quantitativa em um espaço onde eu pudesse investigar padrões, organizar ideias e transformar curiosidade em análise.

## Tecnologias

| Tecnologia   | Uso                                       |
| ------------ | ----------------------------------------- |
| Next.js 16   | Framework principal e roteamento dinâmico |
| React        | Componentização da interface              |
| Tailwind CSS | Estilização responsiva                    |
| JavaScript   | Lógica e interações                       |
| Vercel       | Deploy em produção                        |

---

## Funcionalidades

* Interface editorial responsiva com identidade visual minimalista
* Páginas dinâmicas por ensaio via roteamento `[slug]`
* Hero sections com gradientes e sobreposições visuais
* Navbar com efeito glassmorphism
* Micro-interações suaves em hover
* Build otimizada com Next.js

---

## Estrutura do projeto

```bash
/app
  /ensaios
    /[slug]       # Página dinâmica de cada ensaio
  /sobre          # Página me apresentando e o motivo o qual eu criei o site
```
